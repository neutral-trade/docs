# 交易机构基础设施

仅有一套盈利策略，还不足以管理外部资金。您还需要：在每个交易场所开立账户、为每家交易所配备托管方、为链上场所配备 MPC 钱包、在各场所之间调拨保证金的方式、每日 NAV、针对每位投资者的费用核算，以及报告体系。大多数交易机构每接一位投资者，就要以一个新的管理账户重建一遍这套体系。

Neutral Trade 已将这套体系一次性建成，作为共享基础设施。您只需将策略接入 [Neutral Strategy Vault](../zhong-xing-ce-le-jin-ku/yun-zuo-ji-zhi.md) 并进行交易，其余工作由我们运作。

## 一次请求，完成保证金调拨

跨场所策略需要在正确的时间把保证金放在正确的位置。Transfer API 只需一次请求：来源场所、目标场所、金额与币种。Neutral Trade 以 USDC 经由白名单 MPC 接收地址与 Circle 的跨链转账协议（CCTP）完成路由，并确认到账。

您无需手动从一家交易所提币再充值到另一家，也不存在输错地址的风险。

## 核算与计费，全部自动化

* **每日 NAV。** 我们通过各场所的只读 API 密钥读取实时账户权益，按实时汇率将保证金折算为 USDC，并每日将价格发布至金库的链上预言机。份额按该 NAV 铸造与赎回。
* **一个账户，众多投资者。** 您只需管理一个账户。金库在链上记录每位存款人的份额。
* **高水位线计费。** 绩效费按钱包逐一计算，基于各自的高水位线，并自动结算。您无需开具发票，也不承担收款风险。Neutral Trade 按协议约定分享部分绩效费，并向存款人收取 1% 的管理费，用于托管与运营。
* **月末对账单。** 每个月末您会收到费用与分配对账单。

这取代了基金行政管理人的 NAV 计算，以及您的账簿、托管方与交易所之间的月度对账。

## 您唯一的例行事项

在中心化交易所，存款以 USDC 形式到达该场所的现货账户。将其划转至您的交易账户即可交易。

每次提款批次处理前，报告机器人会告诉您需要在现货账户中备好多少 USDC。您只需将这笔金额从交易账户划转至现货账户，可以手动操作，也可以通过交易所 API 完成。其余由 Neutral Trade 完成：从现货账户提取、链上结算，并支付给每位存款人。Neutral Trade 从不从未平仓头寸中提取资金。

其他交易场所遵循相同方式，使用准入时约定的账户。处理时间与提款安排在您的金库条款中约定，准入时您收到的运营指南会列出具体步骤。

## 报告

您的金库配有专属 Telegram 报告机器人，发送：

* 每日存款与提款确认
* 每次提款批次前的通知：需在现货账户中备好的 USDC 金额
* 每周资金流报告：已解锁提款、待处理提款与净流量
* 月末费用与分配对账单

您的运营团队与投资者依据同一套每日数据工作。

## 存款人可以自行验证的结构

您仅获得执行权限。无论是您还是 Neutral Trade，都无法将金库资金提取至任意外部地址。每一笔资金流动都仅限于预先批准的地址、合约与托管路径。

这保护了存款人，也帮助您募集资金：资本配置者在存款前，无需仅凭您的说法来相信托管安排。详见 [金库安全机制](../zhong-xing-ce-le-jin-ku/jin-ku-an-quan-ji-zhi.md) 与 [安全机制](../zhong-xing-ce-le-jin-ku/an-quan-ji-zhi.md)。

## 用好 Neutral Trade 的九个习惯 <a href="#get-the-most" id="get-the-most"></a>

您带来策略。在 Neutral Trade 上表现最好的机构，也会充分利用策略之外的平台能力。以下九个习惯能保护您的净收益，让运营更省心，并帮助您的金库募集资金。

1. **选择最优费率等级交易。** 您的等级或我们的等级。如果您的 VIP 等级或返佣优于我们，就在您自己的子账户中交易，并在上线前确认该等级已生效。您自己的账簿与金库收益之间的大多数差异，都来自费率等级差。
2. **设定适合您交易台的金库条款。** 上线前，我们会与您约定申购安排、赎回通知期、存款锁定期（如有）以及容量上限。请根据交易台的值守时间与平仓速度来设定。被迫平仓更少，表现更稳定。
3. **让我们调拨您的保证金。** 场所之间每次调拨只需一次请求。无需手动提币与充值，也不会输错地址。
4. **用同一个数据源完成每日管控。** 存款、提款、每日权益、每周资金流汇总与费用通知，都会发送到您的运营群。您的交易台与存款人依据同一套数据工作。
5. **让费用自动收取。** 绩效费按存款人逐一计算，基于各自的高水位线，每月收取并支付给您。无需发票，没有收款风险。
6. **建立资本配置者可以核验的业绩记录。** 链上 NAV，且仅有交易权限：机构可以交易，但无法提取资金。资本配置者可自行核验您的业绩记录与托管安排，尽职调查更快完成。
7. **与您的存款人沟通。** 在金库页面发布简短的月度评述——发生了什么、您调整了什么、您的预期是什么——能留住存款人。提供背景，不披露仓位。您可以化名上线。
8. **分阶段成长。** 条款确定后约 3–4 周，您的金库即在 Neutral Marketplace 上线。表现良好满 3 个月以上后，将升级至 Neutral Curated。您也可以基于同一套基础设施，为自己的投资者运行私募金库；已有实盘金库的合作伙伴推出第二个策略时享有优先权。
9. **提供 VIP 等级，吸引更大额的资金。** 按存款人在您金库中的余额设定 Silver、Gold、Diamond 三档等级，每档享有相应的绩效费折扣。存款人在应用内申领等级，折扣在链上应用到其钱包。无需改变您的标准费率，即可吸引更大额的存款人。
