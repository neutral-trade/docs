# 策略管理人准入流程

Neutral Trade 邀请系统化交易团队以 **Neutral Strategy Vaults** 的形式运行策略：您负责交易，我们带来资金、基础设施与运营。策略知识产权完全归您所有。

### 谁适合申请

我们寻找的团队，其策略需满足以下基本要求：

* **夏普比率 1.5 以上**（以实盘表现为准；与现有金库具备真实去相关性的策略可酌情放宽）
* **低市场方向性** —— 持续性的方向性策略不适配
* **全自动化系统化执行** —— 不接受主观交易
* **日频或更高频率的信号**
* **可验证的实盘记录** —— 带时间戳的每日盈亏与交易日志；仅有回测不足以通过

相比与我们现有策略组合重叠的大容量策略，我们往往更青睐真正低相关的细分策略。完整的评估标准、评分权重与决策门槛，请见 [策略管理人遴选](ce-le-guan-li-ren-lin-xuan.md)。

### 您将获得什么

您保留策略，其余一切由我们运作。

* **一个账户，众多投资者** —— 您只需管理一个账户；Neutral Trade 汇集存款人资金，并按钱包完成份额核算。
* **自动化费用分配** —— 绩效费按钱包逐一计算，基于各自的高水位线，自动支付。
* **面向大额存款人的 VIP 等级** —— 设定 Silver、Gold、Diamond 三档等级，每档享有相应的绩效费折扣，以吸引更大额的资金。
* **您的费率等级或我们的** —— 在您自己的子账户（MSA）中按您的等级交易，或在我们提供的托管子账户（SMA）中按我们的等级交易。
* **9 个交易场所，均已完成集成** —— Binance、KuCoin、OKX、Bybit、Gate、Bitget、Hyperliquid、Lighter 以及一家 TradFi 券商，托管由 Ceffu、Copper 与 Fordefi MPC 提供。
* **知识产权始终归您** —— 无需披露代码，无复制承诺，无独家绑定，无竞业限制。
* **全方位运营支持** —— 投资者关系、技术接入、市场推广，以及用于自动调拨资金的专有保证金管理系统。

完整的技术栈——交易场所、托管路径、保证金调拨、每日 NAV 与报告——请见 [交易机构基础设施](jiao-yi-ji-gou-ji-chu-she-shi.md)。

### 准入流程

#### 第 1 步 —— 申请

填写 [谷歌表单](https://forms.gle/wKKsqBZmwLkZW4gk8)，通过 [Telegram](https://t.me/neutraltrade) 联系团队，或发送邮件至 [partnerships@neutral.trade](mailto:partnerships@neutral.trade)，介绍您的策略与业绩记录。您将收到我们的标准化尽职调查问卷（DDQ），内容涵盖策略、业绩、风控框架、运营、法律与商业条款。

#### 第 2 步 —— 尽职调查审核

我们将按 [策略管理人遴选](ce-le-guan-li-ren-lin-xuan.md) 中的六维度框架为您的团队评分。我们会要求提供带时间戳的每日盈亏、历史交易日志；对于较大额度的配置，还会要求提供交易所只读 API 权限以核验业绩。背景调查也是这一阶段的一部分。

#### 第 3 步 —— 法律与合规 _（通过审核后第 1–2 周）_

* 签署保密协议（NDA）
* 完成 KYC/AML 验证
* 签署策略管理人协议，包括费用条款
* 约定报告义务与频率

#### 第 4 步 —— 技术接入 _（第 2 周）_

* 建立 API 连接（先开通只读监控权限）
* 对齐报告格式
* 接入 Neutral Trade 的风险监控
* 与 NT 团队建立专属沟通渠道
* Neutral Trade 金库工具使用培训

#### 第 5 步 —— 试运行期 _（第 3–4 周）_

您的金库将在试运行机制下以初始配置资金上线：

* 按您申报的风险限额进行每日监控
* 每周复盘会议
* 对照尽职调查阶段设定的预期跟踪表现

#### 第 6 步 —— 在 Neutral Marketplace 上线 _（条款确定后约 3–4 周）_

试运行顺利完成后，您的金库将在 Neutral Marketplace 上线并向存款人开放。监控转为标准的持续监控机制，并按季度进行复盘。

#### 第 7 步 —— 进入 Neutral Curated _（表现良好满 3 个月以上后）_

您的金库将升级至 Neutral Curated——我们的精选策略阵容，并获得全面的市场推广支持。

上线后如何充分利用平台，请见 [交易机构基础设施](jiao-yi-ji-gou-ji-chu-she-shi.md#get-the-most) 中的九个习惯。

{% hint style="info" %}
**持续要求：** 策略管理人需保持只读 API 可见性，按约定的报告频率提交报告（优先每日），并在准入阶段记录的风险限额内运作。触及每日或每周亏损限额时，将启动第 3 步中约定的升级处理程序。
{% endhint %}
