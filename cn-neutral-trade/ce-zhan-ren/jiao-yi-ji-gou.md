# 交易机构

Neutral Trade 上的每一个金库均由通过我们策略管理人遴选框架的专业交易机构运作——该框架包括已验证的实盘记录、风控审查与运营尽职调查。

部分机构以**公开化名**运作（例如“D Research”）。这些自营交易机构的商业协议禁止公开其法定名称。化名不会改变我们的任何流程：**我们始终确切掌握该机构的真实身份。** 我们会对法定实体完成完整的 KYB，将实盘记录与交易所数据核对，并持有只读 API 权限以监控实时仓位。化名仅决定我们公开什么，而不影响我们验证什么。

{% hint style="info" %}
**本页“已审核”的含义：** 下列每家机构在我们的六维度框架（策略与实盘记录、风险管理、基础设施、运营成熟度、交易对手与法律、利益一致性）中均至少获得 3.5/5.0 分。详见：策略管理人遴选。
{% endhint %}

### 我们会为每家机构公开的信息

| 字段     | 含义                         |
| ------ | -------------------------- |

| 验证     | Neutral Trade 在准入阶段独立验证的内容 |

### Neutral Trade 如何验证这些信息

本页每一项数据都会在准入阶段核实，并持续监控：

* **实盘记录** — 带时间戳的每日盈亏与历史交易日志，与交易所对账单交叉核对；对于较大额度的配置，还会取得交易所只读 API 权限。
* **实时监控** — Neutral Trade 对金库交易账户拥有只读可见性；仓位与盈亏每日对账。
* **法律** — 在配置任何资金之前，对每个化名背后的法定实体完成完整 KYB、受益所有权披露与签署商业协议。

{% hint style="warning" %}
管理规模等数据由机构自行报送，并在准入阶段经过验证；这些数据会随时间变化，我们会定期更新，但非实时更新。
{% endhint %}
