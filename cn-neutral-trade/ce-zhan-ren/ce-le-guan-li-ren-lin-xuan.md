# 策略管理人遴选

Neutral Trade 仅上架由通过标准化审核框架的交易团队所运作的策略。每一位候选策略管理人都会在**六个加权维度**上接受评估，按统一标准评分，并对照固定的决策矩阵进行审核。该框架的设计优先考虑对存款人而言最关键的风险管理与收益质量因素。

{% hint style="info" %}
**这对存款人意味着什么：** Neutral Trade 上的每一个金库，背后都是一支通过了实盘记录核实、风控审查与运营尽职调查的交易团队——而不只是一份路演材料。
{% endhint %}

### 评分方法

每个维度按 1–5 分评分，并汇总为加权平均分：

| 评级  | 分数 | 说明             |
| --- | -- | -------------- |
| 优秀  | 5  | 超出要求，达到机构级水平   |
| 良好  | 4  | 满足全部要求，并具备显著优势 |
| 合格  | 3  | 满足最低要求         |
| 勉强  | 2  | 低于要求，需整改       |
| 不合格 | 1  | 未达到标准          |

**最低通过分数：3.5 / 5.0（加权平均 70%）。** 低于该阈值的团队不予准入。

### 六个评估维度

#### 1. 策略与实盘记录 — 25%

与风险管理并列为权重最高的维度。

* **实盘交易时长** — 3 年以上实盘交易得分最高；不足 6 个月则不合格。仅有回测永远不够。
* **业绩质量** — 年化收益、夏普比率（预期 1.5 以上；2.0 以上为优）、最大回撤（优选低于 15%）、胜率，以及逐月收益的稳定性。
* **策略清晰度** — 明确表述的优势来源、合适的资产范围，以及完全系统化的执行模型。含人工环节的部分需要明确的理由说明。

**验证是必需项，而非可选项。** 我们要求提供带时间戳的每日盈亏与历史交易日志；对于较大额度的配置，还需提供交易所只读 API 权限。经第三方审计的收益数据为强烈优先。仅凭自行填报的表格不被接受为唯一证据。

> 若某策略与我们现有金库组合具有卓越的去相关性，则即使夏普比率低于标准阈值，也可能获得准入资格。

#### 2. 风险管理 — 25%

* **敞口控制** — 明确的总敞口限额（在有清晰理由的前提下，3–4 倍杠杆可接受；未定义限额则不合格）、与市场中性声明相符的净敞口区间，以及单一资产集中度限额（优选低于 30%）。
* **回撤管理** — 硬性日度亏损限额、周度升级阈值、成文的降风险流程，以及回撤后明确的重新入场标准。
* **运营风险** — 系统冗余与故障转移、以多场所执行降低交易对手风险、自动化系统的人工接管能力，以及良好（或已透明说明）的事故历史。

#### 3. 基础设施与技术 — 15%

* **执行** — 自研执行基础设施得分最高；延迟与订单类型支持必须与策略类型匹配；滑点管理必须有成文记录。
* **研究流程** — 数据源质量、系统化的策略开发、回测严谨性（样本外测试、市场制度分析），以及合理的模型更新节奏。
* **安全** — 禁用提币权限且启用 IP 白名单的 API 密钥、含访问控制的版本化代码管理，以及完整的审计追踪记录。

#### 4. 运营成熟度 — 15%

* **团队** — 不依赖单一关键人物的团队深度、相关量化/加密经验、明确的职责分工，以及连续性安排。单人运作的团队将面临更严格的关键人物风险审查。
* **管理规模与容量** — 具备一定规模的现有管理资产、对策略容量的现实估计，以及在不损害业绩的前提下吸纳 Neutral Trade 配置的空间。
* **报告** — 优选每日报告（最低每周）、标准化格式、及时的沟通响应，以及愿意提供实时只读 API 可见性。

#### 5. 交易对手与法律 — 10%

* 合适的法定实体架构与司法管辖区、监管状态与运营历史。
* 文件审查：实体设立文件、受益所有权披露、AML/KYC 政策，以及保险覆盖。
* 向现有投资人、交易所合作方与服务提供商进行背景核实。

#### 6. 利益一致性与契合度 — 10%

* **组合契合度** — 对现有金库组合的分散价值、与当前配置的低相关性，以及有限的资产重叠。相较于容量更大但与现有金库重叠的策略，我们往往更偏好真正不相关的利基策略。
* **商业条款** — 有竞争力的费率、可接受的流动性与赎回条款，以及满足我们透明度标准的意愿。
* **合作潜力** — 可持续的商业模式、一致的增长激励，以及及时的沟通响应。

### 决策矩阵

| 加权得分      | 结果        | 后续安排                    |
| --------- | --------- | ----------------------- |
| 4.5 – 5.0 | **强烈通过**  | 快速准入；可考虑更大的初始配置额        |
| 3.5 – 4.4 | **通过**    | 标准准入流程，并需完成已识别的整改事项     |
| 3.0 – 3.4 | **有条件通过** | 在任何配置之前必须完成重大整改         |
| 2.0 – 2.9 | **拒绝**    | 存在实质性缺陷；可在 6–12 个月后重新申请 |
| 低于 2.0    | **直接拒绝**  | 根本性不匹配                  |

### 自动触发的红线

以下情形将立即触发升级审查，并无论总分如何都将阻断准入：

* 无法验证实盘记录
* 存在重大运营事故历史
* 未披露的重大风险
* 监管问题或制裁风险敞口
* 拒绝提供标准文件
* 报送数据前后不一致
* 尽职调查期间关键人物离职
* 背景核实结果不利

### 尽职调查问卷

每一支候选团队都需完成一份标准化 DDQ，涵盖六个方面：策略概述与优势来源、历史业绩数据、风险框架与事故历史、运营（团队、基础设施、安全）、法律与合规，以及商业条款。DDQ 的回答会直接计入上述各维度评分。
