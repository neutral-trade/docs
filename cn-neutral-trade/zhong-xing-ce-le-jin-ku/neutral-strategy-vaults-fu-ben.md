# Neutral Strategy Vaults 副本

**全自动执行，无需人工干预**

* 从跨链与资金部署、仓位管理到退出执行，策略全流程实现自动化运行与优化。
* 依托机构级信号体系与实时监控系统，持续优化收益获取与风险敞口管理。
* 通过最大限度减少人工参与，策略可实现 7×24 小时不间断运行，在保证执行效率的同时，实现更具规模效应且成本可控的策略执行。

**从 Solana 出发，布局全市场策略机会**

* 以 Solana 为唯一资金入口，无需跨链，无需管理多个钱包。
* 通过 Neutral Trade，您可一站式接入经过严格筛选的多元化 CeDeFi 策略，覆盖主流公链与核心交易场所。
* 资金可根据市场条件灵活部署至最具优势的执行环境，充分利用深度流动性，以获取更优价格、更低滑点及更具竞争力的收益表现。

**机构级基础设施，链上透明可验证**

* 资产通过值得信赖的机构级场外托管与结算服务商进行管理，包括 **Copper** 与 **Ceffu**。
* 所有交易、策略操作及资金流转均记录于链上，实现全流程透明化与可验证性，让资金运作情况清晰可查。

### 2. 系统架构

<figure><img src="../.gitbook/assets/image (42).png" alt=""><figcaption></figcaption></figure>

#### 2.1 系统核心角色

* **用户：** 用户可向 Neutral Vault 存入或提取资金。其相关数据及业绩指标（如高水位线、高水位净值、持有份额等）均记录并更新于链上。
*   **Neutral Vault (NV):** 作为系统的核心资金池，负责连接用户与策略执行层之间的资金流转。

    Neutral Vault 维护所有关键运营数据，包括：总份额（Total Shares）、待处理存款与提现申请、存款额度上限（Deposit Cap）、净资产价值（NAV）。
* **NV 主控账户:** 拥有协议层级管理权限，负责 NV Manager 的授权、白名单管理及权限控制。
* **NV 管理员：**&#x8D1F;责创建和配置 Neutral 金库，并拥有以下管理权限：更新策略参数（如费用结构）、管理 Keeper 与 Executor、提取已产生的管理费及业绩报酬。
* **NV Keeper:** 负责执行日常运营任务，包括：存款与提现申请的批量处理、向执行层部署资金、费用计算与计提、NAV 更新与记录维护。
* **策略执行器：**&#x4ECE; Neutral Vault 接收资金，并根据实时交易信号将资金部署至对应的交易场所与策略。
* **自动化监控系统：**&#x8D1F;责承载与执行策略逻辑，并持续监控实时市场状况。其主要职责包括：生成交易信号、管理策略运行流程、发出平仓指令、执行跨链与资金调拨、协调 Neutral Vault 与执行器之间的资金流转。
* **协议与交易所：** 策略实际执行的底层场所。对于中心化交易平台（CeFi），系统通过 **Copper** 与 **Ceffu** 等安全场外托管及结算服务商接入交易所环境，以实现机构级资金安全与执行效率。

#### 2.2 运行周期

1. 用户通过平台界面发起存款或提现申请。
2. NV Keeper 会定期暂停接受新的申请，以准备存款与提现请求的批量处理流程。
3. NV Keeper 依据最新的净资产价值（NAV）统一处理待执行的存款与提现申请。
4.  完成存款处理后，资金将按照 Neutral Vault 预设的执行器分配比例（Allocation Ratio），分配至对应的策略执行器（Executors）。

    随后，执行器根据策略要求，将资金部署至相应的协议与交易场所。
5. 完成本轮处理后，NV Keeper 将解除暂停状态，重新开放金库，接受新的存款与提现申请。

#### 2.3 费用类型

*   **服务费：**&#x670D;务费根据持有时间及 Neutral Vault 设定的服务费率计算。该费用以份额（Shares）形式计提，即通过扣减用户持有份额的方式收取，而非直接扣除资产。

    累积的服务费份额可由 NV 管理员随时提取。&#x20;
* **业绩报酬：** 当当前份额净值高于用户的高水位线（High-Water Mark，HWM）时，系统将对超出部分收益按预设业绩报酬费率计提业绩报酬。计提完成后，用户的 HWM 将更新为新的份额净值。若用户在当前份额净值低于既有 HWM 时追加存款，则新的 HWM 将按照加权平均方式重新计算：原有份额继续适用原 HWM；新增资金适用其对应的入场净值；最终形成新的综合 HWM。与服务费相同，业绩报酬同样以**份额形式计提**，并通过扣减用户持有份额进行收取。累积的业绩报酬份额可由 NV Manager 随时提取。
* **存款费：**&#x5B58;款费将在发行金库份额前，从用户存入金额中直接扣除。因此，最终用于计算份额的实际入金金额将低于用户提交的存款金额。&#x20;
* **提现费：** 提现费在赎回时收取。用户实际收到的资金金额将在赎回金额基础上扣除适用的提现费用后进行结算。

### 3. 存取款

#### 3.1 存取款流程

**1. 连接钱包**

* 使用您常用的 Solana 兼容钱包进行连接。
* 台通过 ReOwn 提供钱包接入服务，支持大多数主流 Solana 钱包。

**2. 提交存款申请**

* 用户可申请向 Neutral Vault（NV）存入资金；
* 所有申请通常会在 **24 小时内**完成处理；
* 存款金额需满足该 NV 规定的最低存款要求；
* 若 NV 已达到 TVL 上限，申请可能被拒绝；
* 存款申请提交后，在当前申请完成处理前，用户无法再次提交新的存款或提现申请；存款申请一经提交，不可撤销。

**3. 存款处理与份额发行**

* 存款申请将在扣除适用的存款费用后，以批量方式统一处理。
* 处理完成后，资金将部署至对应策略进行运作。
* 用户将获得相应的 **NV 份额（NV Shares）**，用于代表其在 NV 总资产中的按比例所有权。

**4. 存款完成后**

* NV 份额净值将随底层策略表现而变动；
* 部分 NV 设有锁定期，在锁定期结束前无法发起提现申请；
* 服务费及业绩报酬（如适用）将按照既定规则定期计提。

**5. 提交提现申请**

* 用户可申请赎回其所持有的 NV 资产份额；
* 提现申请可能需经过赎回等待期（Cooldown Period），具体时长因策略而异；
* 在等待期内，NV Manager 将根据需要逐步平仓并准备相应资产，以满足赎回需求；
* 提现申请提交后，在当前申请完成处理前，用户无法再次提交新的存款或提现申请；提现申请一经提交，不可撤销。

**6. 提现处理与份额赎回**

* 赎回等待期结束后，用户将自动收到对应的 NV 资产份额，到账金额将扣除适用的：提现费、服务费、业绩报酬
* 提现完成后，相应的 NV 份额（NV Shares）将被销毁，以反映用户持有权益的减少。
* 在赎回等待期结束后，提现通常会自动处理，并于 24 小时内发放至用户钱包。
