# NT Earn

NT Earn 是一个基于 Neutral Strategy Vaults 基础设施构建的 USDC 借贷聚合器。它会自动将您的 USDC 配置到 Solana 主流借贷协议中，优化目标是风险调整后的收益，而非名义 APY。

**零费用。1 小时内可提款。**

## 运作方式

当您存入 USDC 时，NT Earn 会将其分配到一组精选的 Solana 借贷市场中。这一配置并非静态：系统会持续监控借款需求、资金利用率与池深度，并向收益最高的市场再平衡，同时避免承担过度集中风险。

这与直接存入单一协议不同。单一协议的存入完全暴露于该协议的利用率波动与智能合约风险。NT Earn 则同时持有多个协议的仓位，并在利用率达到压力阈值时自动退出。

## 配置方法论

配置引擎并不追逐名义上最高的 APY，而是在部署资金前综合衡量多个因素。

**协议与市场筛选标准：**

| 因素      | 我们评估什么                |
| ------- | --------------------- |
| 资金利用率   | 利用率过高会减少可用于提款的流动性     |
| 借款需求    | 资金仅流向有活跃借款人的池         |
| 池深度     | 深度不足或出借方高度集中的池会产生提款风险 |
| 供给/借款上限 | 系统在配置前会模拟存入后的影响       |
| 抵押品质量   | 发行方风险、信用风险与清算坏账可能性    |
| 预言机质量   | 价格馈送的可靠性与抗操纵能力        |

### **配置逻辑：**

1. 按当前 APY 对可用市场排序
2. 检查入场阻断规则（利用率阈值、上限限制）
3. 模拟存入后的市场影响——仅在借款需求能够吸纳该笔资金且不会显著摊薄收益时才部署
4. 先配置到 APY 最高的市场直至其容量上限，再将剩余资金流向次高者

**提款顺序：** 当您赎回时，系统会优先退出 APY 最低的仓位，尽可能长地保留您收益最高的配置。

### 自动退出机制

系统持续监控利用率，若出现压力状况，会按阶梯式顺序退出仓位——您无需自行监控。

| 压力级别 | 应对措施      |
| ---- | --------- |
| 轻度   | 部分减仓      |
| 中度   | 提高退出比例    |
| 严重   | 100% 立即退出 |

若任一市场的利用率超过退出阈值，新的存入将被完全阻断，以防止将新资金投入处于压力中的池。

## 风险

NT Earn 全程持有 USDC，不对加密价格承担任何方向性敞口。但它仍承担 DeFi 借贷特有的风险：

**智能合约风险**

**预言机风险** — 借贷协议的清算依赖价格预言机。预言机馈送遭受操纵或失效，可能在底层池中产生坏账，从而影响出借方收益。

**流动性风险** — 在极端市场条件下，多个协议同时出现高利用率，可能使提款超出标准的 1 小时窗口。自动退出机制旨在降低这一风险，但无法完全消除。
