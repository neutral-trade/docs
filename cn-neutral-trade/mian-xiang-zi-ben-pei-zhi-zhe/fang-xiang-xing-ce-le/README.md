# 方向性策略

方向性策略基于量化信号、动量、均值回归与波动率制度识别建立系统化仓位。与市场中性方法不同，这类策略与加密市场的整体走势存在一定相关性。

本板块下的所有策略均由外部策略管理人团队运作，这些团队都已通过 Neutral Trade 的审核流程，包括业绩实盘记录审查、夏普比率评估与运营尽职调查。
