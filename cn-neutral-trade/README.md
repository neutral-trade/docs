# 项目介绍

_分配者可以投资于各类策略，交易者则可通过“中性策略金库”在链上筹集资金。_

**Neutral Trade** 是是一个为资金配置方精选系统化策略的平台，同时也是面向交易团队的资本募集基础设施。

我们提供覆盖中心化与去中心化市场的系统化策略，以透明、无需许可的方式，让用户能够接触原本仅向专业交易台开放的策略与机会。

我们的团队融合了来自高盛（Goldman Sachs）及全球前三对冲基金的经验，并在 DeFi 协议机制方面拥有深厚的专业能力。
