# 分销合作伙伴

分销合作伙伴可将 Neutral Trade 的收益型金库直接集成到自己的产品中，使其用户无需自行搭建基础设施，即可获得机构级收益。

**分销合作伙伴的收入模式**

| 集成方式       | 说明                                                       | 收入分成    |
| ---------- | -------------------------------------------------------- | ------- |
| **集成现有金库** | 对接 Neutral Trade 现有的精选金库。根据您为金库带来的 TVL，与金库策略管理人达成费用分成协议。 | 分成比例可协商 |

**费用分成如何在链上结算**

费用分成由金库程序通过其推荐（“builder code”）系统原生处理，因此归因与支付均在链上透明可验证：

* 您带来的存款会通过您的推荐码，在链上归属到您的合作伙伴账户。
* 您将获得这些存款所产生的**业绩报酬与管理费**中约定比例的分成。该分成从金库管理方的费用中划出，**不会增加您用户所支付的费用**。
* 费率按合作伙伴协议配置，并可在符合资格条件的前提下按金库逐一调整。
* 您累计的分成会以金库份额的形式在链上累积，并通过链上的“申请—提取”流程领取，使用与普通提款相同的赎回机制。

由于整个流程均运行在金库程序内，您所赚取的分成可随时对照程序 [IDL](api-and-sdk-and-idl.md) 进行审计。

**分销合作伙伴的优势**

分销合作伙伴可获得一套开箱即用的解决方案，以极小的开发投入向用户提供具备竞争力的收益。主要优势包括：可通过 API 或 SDK 无缝集成的即插即用、可白标的收益金库；以链上收益差异化您的产品并提升用户留存；专属客户经理与集成技术支持；以及用于跟踪业绩与收益的实时报告与分析看板。

4. **上线：** 启动您集成的收益产品，开始赚取收入。
